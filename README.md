# folio.didoo.net

Personal portfolio of Cristiano Rastelli: a plain static website, hosted on GitHub Pages.

There is no build step. The `docs/` folder _is_ the website, published from the `main` branch.

```sh
npm install      # only needed once, for the checks
npm run serve    # preview at http://localhost:8000
npm run check    # lint the CSS and the HTML, and verify all the local links
```

See `CLAUDE.md` for the structure of the site and how to add a new case study.
